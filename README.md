☁️ CloudBox

CloudBox é uma aplicação de armazenamento em nuvem inspirada no Dropbox, permitindo upload, listagem e gerenciamento de arquivos em tempo real.

Este projeto foi desenvolvido com foco em aprendizado prático de desenvolvimento fullstack, incluindo backend, frontend e deploy.

🚀 Funcionalidades
📁 Upload de arquivos
📂 Listagem de arquivos enviados
🔄 Atualização em tempo real
🗑️ Remoção de arquivos
🌐 Integração com armazenamento na nuvem
🧱 Tecnologias utilizadas
Backend
Node.js
Express
MongoDB
Mongoose
Multer (upload de arquivos)
Frontend

⚙️ Como rodar o projeto
🔧 Pré-requisitos
Node.js instalado
MongoDB (local ou na nuvem)
▶️ Backend
cd backend
npm install
npm start
▶️ Frontend
cd frontend
npm install
npm start
🌍 Variáveis de ambiente

Crie um arquivo .env no backend:

MONGO_URL=your_mongodb_connection_string
PORT=3333
